# Context-OS Client v0.4.0

- **Date**: 2026-08-30
- **Product**: Context-OS Client (Windows x64 NSIS)
- **SemVer**: `0.4.0`（MINOR：壳能力——自动更新）
- **Source of truth**: `desktop/package.json` + `desktop/src-tauri/tauri.conf.json` + `desktop/src-tauri/Cargo.toml`
- **Business model**: ADR-0010（免费客户端；云端分享名额 + 钱包；无激活闸）
- **Baseline**: trunk `74b1e281`（2026-08-30）

## User-visible changes

1. **自动更新上线**（本 MINOR 的核心）：设置 → 关于 →「检查更新」。查新 → 发现新版本 → 「下载并安装」→ 下载（带百分比进度）→ NSIS 静默升级 → 应用自动重启。更新源 `https://app.contextlm.top/releases/desktop/updates.json`，更新包经 minisign 签名校验（`tauri-plugin-updater`，公钥内置于客户端）。
2. **对齐 trunk**：本机库与云端产品代码自 v0.3.1（08-19）以来的全部修复进入安装包，含：ingestion 独立中继池后的本地侧配套、登录卡注册引导、local:true 重注册密码自愈、顶栏账户菜单云身份修复、工作区 composer 防呆模式（自动挂 RAG）等（详见 git log `fe22bb58..74b1e281`）。
3. Sidecars（`avrag-api` / `avrag-worker`）自当前 trunk 重新交叉编译（08-19 产物已过期 40+ 个提交）。

## Known issues

- Authenticode 未签 / 自签 → SmartScreen「未知发布者」提示，选**仍要运行**。minisign 更新签名不受影响。
- 本次发版为自动更新通道的**首次发布**：存量 0.3.1 客户端无 updater 代码，仍需手动下载本版；0.4.0 起后续版本可自动更新。
- 更新下载期间不校验磁盘剩余空间（NSIS 安装器自身有基本检查）。

## Minimum OS / arch

- Windows 10 64-bit + WebView2
- Artifact: `Context-OS-Client_0.4.0_x64-setup.exe`（NSIS）

## Min cloud API

- `v1`（login / share / wallet / `POST·GET /api/v1/workspaces/publish/*`，不变）

## License / activation

与 0.2 / 0.3 一致：**免费客户端**，无激活闸。云端会员 = 分享名额；平台模型 = 钱包或 BYOK。

## Build & package (local)

```bash
bash scripts/build-windows.sh            # sidecar 交叉编 + 前端 + NSIS（需 desktop/signing/update-key.key）
SIGN_WINDOWS=0 bash scripts/package-desktop-release.sh   # 产出 latest.json + updates.json + SHA256SUMS
bash scripts/publish-desktop-release.sh  # 发布到 VPS /var/www/releases/desktop/
```
