# Context-OS Client v0.2.0

- **Date**: 2026-08-10  
- **Product**: Context-OS Client (Windows x64 NSIS)  
- **SemVer**: `0.2.0`  
- **Source of truth**: `desktop/package.json` + `desktop/src-tauri/tauri.conf.json` + `desktop/src-tauri/Cargo.toml`  
- **Business model**: ADR-0010 (free client; cloud share slots + wallet; no Keygen activation)  
- **Design / packaging note**: `docs/desktop/2026-08-10-v0.2.0-free-client-release.md`

## User-visible changes

1. **Free client** — no paid desktop license; activation is not a product gate for install or chat.  
2. Installer welcome + EULA copy aligned with ADR-0010 (no “license-first / trial required”).  
3. Sidecars (`avrag-api` / `avrag-worker`) rebuilt against current trunk (verify-loop, BYOK, wallet, share Owner-pays, etc.).  
4. Embedded portable PG+pgvector+Redis unchanged in shape (BR2); product still defaults to local stack.  
5. Optional cloud: membership = shareable workspace slots; platform models = wallet or cloud BYOK — not sold as “desktop activation”.

## Known issues

- Authenticode may be self-signed / unsigned in solo builds → SmartScreen “unknown publisher”; use **Run anyway**.  
- Legacy routes `/activate` and `/desktop/buy` may still exist in the embedded web shell as demoted/history UI; they must not block cold start.  
- **Publish local → cloud** (ADR-0010 B3b) is **not** in this release; local share online still incomplete.  
- Desktop MCP/CLI agent access: see `docs/desktop/LOCAL-CLIENT-MCP-CLI-AGENT-ACCESS.md`.

## Minimum OS / arch

- Windows 10 64-bit + WebView2
