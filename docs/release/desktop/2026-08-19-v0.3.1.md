# Context-OS Client v0.3.1

- **Date**: 2026-08-19  
- **Product**: Context-OS Client (Windows x64 NSIS)  
- **SemVer**: `0.3.1`  
- **Source of truth**: `desktop/package.json` + `desktop/src-tauri/tauri.conf.json` + `desktop/src-tauri/Cargo.toml`  
- **Business model**: ADR-0010 (free client; cloud share slots + wallet; no Keygen activation)  
- **Design**: `docs/desktop/2026-08-10-workspace-publish-b3b-design.md`

`0.3.0` (2026-08-16) already shipped cloud login + official keys **without** workspace Publish in the installer. This patch puts B3b on the same 0.3 line so `/desktop` does not overwrite the old 0.3.0 artifact with a silent feature delta.

## User-visible changes

1. **Publish then share** — from the existing share modal / `/dashboard/:id/share` (no new nav). Local workspace uploads a cloud replica first; share uses the cloud workspace + session JWT.  
2. Share URLs are minted against the **cloud origin**, not the local API.  
3. Until publish is `ready`, online share stays gated. Status fetch failure is not treated as “never published”.  
4. Publish sends index/embeddings (fingerprint-checked), **not** original files or assets. Embedding fingerprint mismatch is rejected; the cloud does not re-embed.  
5. Sidecars (`avrag-api` / `avrag-worker`) rebuilt against current trunk so the bundled local API includes `/publish/*` (the 0.3.0 installer did not).

## Known issues

- Authenticode may be unsigned / self-signed in this solo build → SmartScreen “unknown publisher”; use **Run anyway**.  
- **B4 dirty resync is not in this release.** After the first successful publish, later local edits do not incrementally sync. Re-publish / dirty hash is a later slice.  
- Mid-commit cloud replica is not fully transactional; a failed commit is marked `failed` and upload parts are deleted.  
- Desktop MCP/CLI agent access: see `docs/desktop/LOCAL-CLIENT-MCP-CLI-AGENT-ACCESS.md`.

## Minimum OS / arch

- Windows 10 64-bit + WebView2  
- Artifact: `Context-OS-Client_0.3.1_x64-setup.exe` (NSIS)

## Min cloud API

- `v1` (login, share, wallet, **and** `POST/GET /api/v1/workspaces/publish/*`)

## License / activation

Unchanged from 0.2 / 0.3.0: **free client**, no activation gate. Cloud membership = share slots; platform models = wallet or BYOK.
