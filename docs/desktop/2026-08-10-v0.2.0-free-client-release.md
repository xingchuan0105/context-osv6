# Desktop v0.2.0 — 免费客户端安装包与文档对齐（ADR-0010）

- **日期**: 2026-08-10  
- **状态**: 发版设计 + 构建约定（实现以 `scripts/build-windows.sh` / `package-desktop-release.sh` 为准）  
- **关联**: `docs/adr/0010-share-service-business-model.md` · `docs/desktop/RELEASE-AND-DOWNLOAD.md` · `docs/desktop/SMOKE_CHECKLIST.md` · `docs/release/desktop/2026-08-10-v0.2.0.md`

## 1. 动机

| 旧（v0.1.x 叙事） | 新（v0.2.0 / ADR-0010） |
|------------------|------------------------|
| 桌面买断 / Keygen 激活 / 试用墙 | **客户端免费**；无激活闸 |
| 安装文案「许可优先」 | 安装文案「免费本机使用」 |
| 公网 `latest.json` 仍 0.1.0（2026-08-05） | 重打 **0.2.0** 安装包 + 元数据 |
| 云端卖 token / 客户端许可 | 云端主商品 = **可分享 Workspace 名额**；辅 = 钱包代购；模型优先 BYOK |

云端后端/Web 已于同日前后部署 trunk；桌面安装包若停留在 0.1.0，用户装到的仍是**旧 sidecar + 旧许可叙事**。

## 2. 版本与产物

| 项 | 值 |
|----|-----|
| SemVer | `0.2.0`（MINOR：商业模式与壳叙事；兼容本机数据目录） |
| 版本单一事实 | `desktop/package.json` · `desktop/src-tauri/tauri.conf.json` · `desktop/src-tauri/Cargo.toml` |
| 主产物 | `Context-OS-Client_0.2.0_x64-setup.exe`（NSIS） |
| 发现 | `dist/desktop-release/latest.json` → 可选 `publish-desktop-release.sh` → `/releases/desktop/latest.json` |
| 嵌入 | `avrag-api` / `avrag-worker`（Windows gnu）+ 便携 `runtime/pgsql` + `runtime/redis` + migrations |

**MINOR 选择理由**: 不强制迁移本机 PG 数据布局；破坏性变更留给将来 MAJOR（例如换数据根路径）。

## 3. 安装 → 冷启动旅程（目标）

```text
/desktop 下载 setup.exe
  → NSIS 欢迎（免费客户端文案）→ EULA（无试用/激活前提）→ 安装
  → 启动 Context-OS Client
  → 不强制云 Login；不强制 /activate
  → 本机栈 ensure（PG+pgvector+Redis）
  → 设置本机模型 Key（本地 BYOK）
  → 建库 / 问答
  → 【可选】登录云：分享名额、钱包、云端 BYOK
  → 【未交付】本地 Publish 上云后再 share_enabled（B3b）
```

## 4. 代码与文案触点（本版必改）

## 5. 构建矩阵

| 步骤 | 命令 | 说明 |
|------|------|------|
| 全量交叉编 | `bash scripts/build-windows.sh` | 默认 STAGE_BUILD=1 编 Windows sidecar + frontend export + NSIS |
| 仅打包元数据 | `bash scripts/package-desktop-release.sh` | 读已有 NSIS → `dist/desktop-release/v0.2.0/` + `latest.json` |
| 签名 | 默认自签或 `SIGN_WINDOWS=0` | 生产 OV/EV 用 `WINDOWS_CERTIFICATE_*` |
| 发布 | `bash scripts/publish-desktop-release.sh` | 需 `VPS_MAIN_*` |

耗时量级（WSL，jobs=2）：sidecar release 交叉编 + Tauri **数十分钟级**；勿与全量 `cargo test` 叠跑。

## 6. 验收门

1. `latest.json`（或本地 dist）`version == "0.2.0"`。  
2. NSIS 文件名含 `0.2.0`；SHA256 写入 `SHA256SUMS`。  
3. 干净 Win 机：`SMOKE_CHECKLIST` §1–2（**L2 不得要求激活**）。  
4. 本机 BYOK 问答通过（§4 K3）。  
5. 云端连上后：分享名额 / 钱包叙事与 Web 一致（可选）。

## 7. 风险

| 风险 | 缓解 |
|------|------|
| SmartScreen | 文案「仍可运行」；长期 OV 证书 |
| 旧用户仍看到 activate 入口 | 不挡主路径；后续删路由 |
| sidecar 与云 API 能力差 | VERSIONING 声明 Min cloud API v1；纯本地不依赖 |
| Publish 未交付 | release notes 写明；不承诺「本机一键分享上云」 |
