## 实现范围

- 导航明确区分个人聊天与工作区；工作区总览/创建、分作用域历史和对话草稿。
- 资料/笔记默认收起，顶栏“添加资料”直接选文件；取消选取保持面板收起。宽窗口并排资料，窄窗口以面板详情替换聊天区。
- 已有 create-upload → 签名 PUT → complete-upload 链路；复用 desktop-core 的本机签名 URL 校验、失败清理和重试；处理状态在面板收起后仍轮询。文件类型沿用后端契约，未新建解析器。
- 工作区 RAG 请求携带工作区与所选已完成资料；个人请求不带知识库能力、工作区或资料范围。引用与历史引用可打开授权原文接口。
- 笔记创建、编辑、保存、删除和离开保护；收起面板保留编辑内容；笔记不自动加入检索资料。
- 状态和异步归属由 knowledge_view 管理，视图由 knowledge_render 管理，workspace 模块复用 contracts/web-sdk 并交给现有 Host 执行，无新增后端接口。

## 本批修复

- 上传轮询首次失败属于测试时钟：真实 Host 的 HTTP 使用实际时间，GPUI TestPlatform 的 3 秒 timer 需显式推进虚拟时钟。修正测试后轮询通过，未靠放宽断言或延长超时掩盖失败。
- 审查发现 Load 先发、笔记保存先完成时，迟到 Load 会把旧笔记集合写回。成功写入增加 revision，丢弃较旧读取并重新加载；请求 epoch 和工作区共同约束切换后的回包。增加受控延迟 HTTP 回归验证。
- 保存/删除笔记期间禁用编辑器和重复操作，避免服务端保存快照与编辑基准混淆。
