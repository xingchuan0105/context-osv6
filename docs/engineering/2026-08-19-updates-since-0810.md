## 2. Agent 编排：从三环到 Lead + Workers

**起点（08-10）**：retrieve → synthesis → verify 三环刚收齐，verify 从 short-judge 改名，观察改第三人称，disaster 收口进 `prompts/loop/`。

**定稿（08-11）**：凡 `capabilities[]` 含 `rag` 和/或 `search`，产品路径一律 **Lead Agent + 专用 Worker**。设计权威：`docs/plans/2026-08-11-lead-rag-web-workers-design.md`。质量门对照：`docs/engineering/2026-08-11-quality-gates-lead-workers-对照表.md`。

| 角色 | 做 | 不做 |
|------|----|------|
| **Lead** | 指代消解、写 Task Brief、调度、覆盖度裁决、用户 prose 合成 | 自己 dense/web 找料；把 pack/host 标签拼进主气泡 |
| **RAG Worker** | 短程 SaC（dense / lexical / grep…）→ `evidence_pack_v1` | 调 web；写用户终答 |
| **Web Worker** | host 检索叶子（可多 query + CRW）→ `evidence_pack_v1` | 调 dense/grep；写用户终答 |
| **Host** | Brief/PackGate / `tool_ok_count` / re-brief≤1 / 出站格式闸 | 语义「覆盖够了」拒答；用户主气泡脚注 |

同期落地：

- 产品 YAML **`verify: false`**（无独立 verify LLM；三环代码休眠后按设计收尸，不是再叠第四个模型）。
- **BASE 工具**（`weather_query` / `calculator` / `user_context` …）归 Lead，不塞进 `preferred_source: rag|web`。
- chat 走 **L0 快路径**；search-only 不再把 host web 直灌用户气泡。
- 08-16～18 继续加厚：retrieve/synthesis **分模型**、`[retrieval_worklog]` 事件投影、joint 缺通道打回、**facets 多侧子检索**、coverage gotcha 注入、BASE 工具 stdout 空时仍展示 Ok 数据。

评测锚点（离线 full-149，不进用户信道）：本地分模型后单题 p50 约 73s → 20s；Wafer 一轮到过 **PASS 141/149**；VPS 合并 149 为 **PASS 133**（境外模型改走 VPS，去掉本机 VPN 税）。

## 3. 用户信道：Harness 不再代答

诊断与方案：`docs/engineering/2026-08-10-harness-llm-user-channel-philosophy-diagnosis.md`（§17 已实施）。

三角关系写进 `AGENTS.md` 并落到代码：

1. **用户主气泡 = 模型自然语言**（说明 / 澄清 / 追问均可，措辞由模型自主）。
2. Harness 只报第三人称 observation（预算、空证据、沙箱态）；**不**在 answer 后拼接 disclosure / ceiling /「本 run…」脚注。
3. 失败在环内消化；到顶后 LLM 收束，或极窄灾难兜底（token 尽 / 格式闸耗尽）。
4. 出站格式闸拦协议泄漏（如 `DSML`）；过程 UI 用产品化 progress 键，不是状态机原文。

这是后续 Lead 合成「承认缺口、不硬编」的前置法则，不是文案润色。

## 5. 桌面客户端：v0.2.0 → v0.3.0

### 5.1 v0.2.0（08-10）— 免费客户端

Release notes：`docs/release/desktop/2026-08-10-v0.2.0.md`。设计：`docs/desktop/2026-08-10-v0.2.0-free-client-release.md`。

- 对齐 ADR-0010：**客户端免费**，无 Keygen / 激活墙；收费在云端分享名额与钱包。
- 退役 `/activate`、`/desktop/buy` 作为产品闸。
- 便携 PG+pgvector+Redis 形态不变。
- **Publish 本地→云（B3b）当时未进包**（设计见 `docs/desktop/2026-08-10-workspace-publish-b3b-design.md`，至今未全量实现）。

### 5.2 08-14 产品对齐（本机 RAG 真能问）

聊天不再走壳内 legacy `run_desktop_chat` / `llm-config.json`，改为本机 `avrag-api` `execute_stream`；embedding / rerank 从 `user_provider_secrets` 构造。真机 **L1 全绿**；D-rag-full 产品路径通（当时检索覆盖度仍薄，根因在下一节）。

### 5.3 08-15 Windows 沙箱 + 解析器捆绑

真机 D-rag-full 零检索的根因不是 knockout，而是 **Windows 构建里 bridge 是 `#[cfg(not(unix))]` 存根**。已原生移植：

- 传输：本机 TCP + 一次性 token（Unix 仍是 fd 管道）。
- 遏制：Job Object（失败则降级 per-pid 超时杀掉）。
- 安装树捆绑：embeddable Python、`modes/` + `prompts/`、stdlib-only `markitdown-lite` / `anydoc-lite`、**liteparse `lit.exe` + `pdfium.dll`**。
- 手动「重新索引本机文档」。

交接：`docs/plans/2026-08-15-windows-sandbox-bridge-port-handoff.md`。

### 5.4 v0.3.0（08-16）— 云登录门 + 官方 Key 走余额

计划：`docs/plans/2026-08-15-desktop-cloud-login-official-keys.md`。版本号已 bump 并发过包；**尚未单写** `docs/release/desktop/2026-08-16-v0.3.0.md`。

用户路径：打开客户端 → **云登录**（Rust 侧 HTTPS，不经 WebView fetch）→ 云端铸 `desktop_tokens` → 本机只拿 **relay base + token + 钉住型号**，真实 provider key 不出云。

- `POST /v1/relay/chat/completions`、`/embeddings`、后续 **rerank**；按真实 usage 走钱包（×1.5 代购价）。
- `AVRAG_PLATFORM_KEYS_RELAY=1` 避免本机再扣一次。
- BYOK 仍覆盖 relay；canonical 仍是 `/settings?tab=providers`。
- 设置抽屉改成账户 / 模型 / 数据 / 关于 / 诊断；撤掉「已激活」badge。
- 顶栏账户菜单显示云身份；退出 = 云登出。

首启无网则用不了官方 key（v1 接受）。本地数据仍属 device-derived 本地账户。

## 8. 安全：fail-closed W0–W5

审查：`docs/engineering/2026-08-18-security-audit-ai-product.md`（OWASP LLM Top 10 / RAG Cheat Sheet / 致命三角）。修补：`docs/plans/2026-08-18-security-remediation-plan.md`；审查闭合：`docs/plans/2026-08-18-security-review-fixes.md`。

审查时最高危链路：`code_interpreter` + `client.fetch` 上 **私有数据 × 不可信内容 × 外传通道** 齐聚。本波已断的致命三角与兜底：

| 波次 | 内容 |
|------|------|
| **W0** | 上传签名删硬编码兜底；`E2E_ENABLED` 不再开代理认证（生产硬拒；本地要显式 `TRUST_PROXY_AUTH`） |
| **W1** | 沙箱进程级隔离：`env_clear`、Unix `prlimit`/`pre_exec`、修 import hook（`importlib.subprocess` / `_original_import` / rlimit 探针） |
| **W2** | SSRF + 证据闸；PackGate 记 `intake_redacted`（不进用户气泡） |
| **W3** | 检索 `doc_ids=None` 与空 vec 一样 **返回空**（不再 owner 全库） |
| **W4** | 会话 cookie / CORS fail-closed；cookie `Secure` 仅 https（localhost HTTP 仍能设上） |
| **W5** | 计量/metrics、桌面 CSP/IPC、ClamAV fail-closed、摄取隐藏 Unicode |

**仍延期**：P2-14 解析器二进制隔离（需独立执行环境）。

## 9. 运行时、并发与部署

抗并发交接：`docs/engineering/2026-08-18-concurrency-hardening-handoff.md`。

| 项 | 变化 |
|----|------|
| 限流 | 用户层 429 **前置**（超限不再先烧完 LLM 再拒） |
| 全局 body | 默认 512MB → **64MB**；上传路由单独保留 512MB |
| Redis | `SharedConn` 懒共享；对 E2E 黑洞地址 **fail-fast**（不再 ConnectionManager 重试约 100s 卡死聊天） |
| 缓存 | 对话路径缓存留进程内；Redis 只做限流 + 锁 |
| SSE | 有界 channel(512)，生产 `emit` 真背压 |
| PG | `AVRAG_PG_MAX_CONNECTIONS`（默认 20）+ 慢查询 500ms 告警 |
| 进程 | api / worker 接 SIGTERM，worker 当前 tick 跑完再退 |
| 运行时镜像 | **lit + pdfium** 打进 runtime（修生产 PDF 灌库静默 dead-letter） |
| nginx | host-tagged access log（ctxlm format）；ghost / sparklist / elo 配置进 `deploy/nginx` |
| CI | **删除全部 GitHub Actions workflow**（solo 主干，不养 CI 剧场） |

生产（08-17 部署记录）：Makora DeepSeek + qwen3.7-flash + qwen_web + CRW；env 备份 `/etc/avrag-rs/avrag.env.bak-20260817`。
