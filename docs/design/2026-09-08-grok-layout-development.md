## 验证记录

本轮用户授权 W1 构建及定向验证 15–25 分钟。使用 jobs=2 和单 browser worker；无真实支付、真实模型调用或部署。

- 首轮 Rust 构建通过；lib 4、i18n 3、样式 guard 3 项通过。
- 首轮 70 个浏览器用例：69 通过，1 个导航可达性用例超时。原因是菜单已由 Esc 关闭后，旧 helper 仍等待并点击不存在的遮罩；改为检查可见性并显式验证关闭状态。
- 视觉复核发现空态 transcript 未收缩，导致输入区与标题间隔过大；已修正残留选择器，并新增空态间距断言。
