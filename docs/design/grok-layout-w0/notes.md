# W0 布局样稿说明

状态：待用户确认。样稿是独立静态交互演示，不连接业务接口，未改产品代码或现行 IA。

## 查看方式

打开 `index.html` 评审台，选择场景、视口、主题及附件状态。点击「独立打开」可使用浏览器真实窗口体验响应式布局。评审台工具栏不属于产品界面。

样稿内容：聊天空态、连续对话、Excel 本轮附件、工作区资料收起/展开、设置五个分类。文字、资料名称和账户均为演示数据；按钮不会上传文件、调用模型、修改账户或创建付款。

## 尺寸与行为

| 区域 | 设计值与行为 |
|---|---|
| 主导航 | 桌面 248px，可折叠至 60px；768–1199px 默认 60px，菜单展开可选目的地；手机 248px 抽屉 |
| 上下文顶栏 | 52px；仅当前对象名称与其相关操作；账户在左栏底部 |
| 聊天正文 | 上限 760px；对话内容独立滚动；输入区始终占据可用区域底部 |
| 聊天空态 | 主内容区域中心偏上，短屏缩减顶部空白；不显示知识库开关 |
| composer | 16px 圆角作为布局样稿提案；文本与单工具栏，附件加入后才显示文件条 |
| 图标入口 | 44px 触达区域；桌面发送视觉 36px，手机发送 44px |
| 资料区域 | 336px；1200px 起并排，窄屏为遮罩抽屉；默认关闭 |
| 设置 | 左分类 176px + 48px 间距 + 最大 640px 表单；手机从分类列表进入详情 |
| 主题 | 采用现行 Cream / Void 方向；本样稿只取必要颜色快照，生产实现继续引用 canonical tokens |

## 需要确认的视觉决定

1. 统一左导航与轻顶栏是否符合预期，账户放在左栏底部是否合适。
2. 聊天输入区的高度、16px 圆角及单行工具密度是否合适。16px 超出现行 8px/pill 规则，只有样稿确认后才更新对应规范。
3. 工作区资料默认关闭、宽屏并排和手机抽屉是否符合使用习惯。
4. 设置采用桌面双栏、手机分类详情，是否认可这种层级。

## 与生产实现的明确差别

- 没有 Grok 当前登录态截图：这些是报告方向的可评审样稿，不是像素复刻。
- 页面切换和重置重新加载演示场景；生产需要保持草稿/滚动及桌面导航偏好，样稿未实现这些持久化逻辑。
- 文件状态通过评审台切换；添加按钮插入一个演示 Excel，不弹出真实文件选择器。失败、解析中、超容量禁止演示发送；移除后可正常输入发送。
- 样稿工作区通过资料入口管理持久文件；未添加新的工作区临时附件流程。
- 样稿发送仅追加明确标记的演示回复。模型菜单只展示默认模型与配置入口，不虚构可用模型。
- 未覆盖所有业务页面的成品样式；W0 只确定三类核心布局，W1–W5 仍待执行。

## 评审修正：资料收起与笔记（用户确认后的补充）

- 面板收起只减少常驻内容，不把高频行动藏起来。工作区顶栏始终显示「＋ 添加资料」图标入口，具备名称与提示；点击直接打开文件选择器，取消选择不改变布局。
- 选择文件后开始上传，并展开资料分区显示文件状态；失败在对应条目就地反馈。收起面板不取消任务，资料入口显示处理中数量/错误状态。样稿只模拟触发，不执行上传。
- 「资料」「笔记」都是顶栏可见入口，点击直接打开对应分区，不必先展开再切换。面板内部也可切换两个分区；关闭按钮统一收起面板。
- 笔记保留现有创建、列表、预览与删除能力，生产继续复用现有 NoteEditor；不将笔记当作上传文件。样稿新增笔记输入和本页演示保存，未模拟真实删除。
- 同一工作区内切换资料/笔记、收起再打开，都保留笔记草稿；切换工作区或离开页面存在未保存内容时给予离开确认。不得无提示清空。
- 不把工作区「添加资料」移入个人聊天附件按钮：前者是持久工作区资料，后者仅用于当前轮次。
- 本补充属于已认可方向的细化，不再增加一轮整体样稿批准门。验证后按既定计划进入 W1，W2 按这些规则实现工作区。
