## 发现并修复

1. 浏览器 REST 客户端把成功响应也截为 4096 字符，真实会话列表稍长即 JSON 解析失败。现在成功响应完整读取，长度上限仅作用于 HTTP 错误文本；读取错误不再伪装为空字符串。
2. 资料列表误用仅供 POST 上传的路径，真实 API 返回 405；删除路径同样不符。现在列表为 `/api/v1/documents?workspace_id=…`，上传为 `/api/v1/workspaces/{id}/documents`，删除为 `/api/v1/documents/{id}`。移除错误的 SDK 路径/签名，同步模拟服务和契约测试。
3. 分享创建未发送 JSON 请求体，真实 API 返回 415。现在明确发送 `application/json` 和 `role: viewer`。
4. 匿名分享解析漏掉真实接口的 `{success, data, error}` 外层；现按实际契约解析，并检查业务失败和空数据。模拟服务同步使用真实外层及失效语义，不保留平铺对象兼容路径。
5. 工作区左栏没有随新会话深链更新。现在会话 query 变化触发工作台数据刷新；通过真实历史重载及草稿/面板回归。

最初将 405 归因于旧二进制不完整：更新后端后仍然存在，最终证实是 SDK 的资料列表路径错误。本次增量构建并运行当前后端以排除版本偏差，没有修改或提交无关后端代码。
