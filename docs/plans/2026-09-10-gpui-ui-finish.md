# GPUI 原生界面收口

用户要求优先完成 GPUI 的成品界面，随后再扩展 D4。沿用已验收的 Grok 布局基准与 Context-OS 品牌，不以 Rust Web 验收代替原生验收。

## 本批范围与门

1. 公共壳：248/60px 导航；第二入口固定为工作区总览；折叠后仍有图标与短文字；低于 768px 使用原生模态导航抽屉；52px 上下文页头。
2. 聊天：760px 阅读宽度、空态与输入卡片聚合、文本区加单工具栏、助手 Markdown 与复制、用户消息层级、错误及停止提示。只展示已接通功能，个人聊天没有知识库控制。
3. 工作区与资料：总览的创建表单和对象卡片；336px 宽屏资料面板，1200px 以下使用原生抽屉；资料与笔记直接切换，上传任务/选择范围/预览/失败恢复/笔记草稿保留。
4. 服务：统一壳内的状态、明确信息层级和操作区。外观明暗切换及桌面折叠偏好保存在客户端目录；移动抽屉状态不持久化。不制作尚无云会话能力的账户菜单。
5. 验证：用户授权修改后 25–40 分钟 Windows 增量构建、共享 Tauri/GPUI 无头交互与主题布局回归，生成独立验收程序。不使用 Computer Use、不调用模型、不重启现有后端。

门：编译通过 → 既有功能与新布局/抽屉旅程通过 → 产物与证据记录、代码图更新、仅提交本任务文件。失败先修复复验；无头几何与事件测试不称作 GPU 像素或人工视觉验收。
