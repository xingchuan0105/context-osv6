## 已发现的准备问题

FreshStack 有两个重复 ID，一个 ID 对应两种不同正文；所选 12 题的标注证据均不涉及它们。[官方 DataLoader](https://github.com/fresh-stack/freshstack/blob/main/freshstack/datasets/data_loader.py)按源顺序建立 ID 字典，因此后面的同 ID 行覆盖前面行。正式全语料适配将遵循该语义并保留审计；本次没有默默去重后声称全部准备完成。

另有一道候选问题为 7,280 UTF-8 字节，超过原型在线 embedding 的 4,096 字节保护阈值。工具参数长度已放宽，在线输入策略仍需单独校验，不截断题目来规避错误。
