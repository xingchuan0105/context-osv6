# 真失败 11 题推理过程分解——出错步骤定位(2026-08-01)

> 依据:全量 149(094826)11 个真失败题的 model_answer 反推推理链。
> 方法:每题把模型推理拆成 5 步通用链,定位出错步骤 + 证据。

## 通用推理链(文档检索类)

```
① 理解问题(提取可核验主张)
② 生成检索策略(选词: dense/lexical/grep, 词形/同义)
③ 执行检索 & 解析回传(命中行/表/统计)
④ 评估覆盖度(已覆盖/未覆盖/部分)
⑤ 终答(结论 + 引用 + 是否继续检索)
```

## 类1:检索/提取不足(q48, q61, q65, q107, q141)——出错在 ② 或 ③

| 题 | 推理链 & 出错步骤 | 证据 |
|----|------------------|------|
| **q48** | ②✅ ③**半成功**:拿到 2.1 节标题"State Machine Loop Boundary",但**未深挖该节正文** → ④ 判"状态列表未覆盖" → ⑤ 诚实拒答。**出错:③(提取深度)**——找到章节标题后停止,应继续 grep/读 2.1 节取 Plan/ExecuteRetrieve/Answer | "回传只覆盖到该节标题...没有返回状态机的具体状态列表" |
| **q61** | ②**出错(检索词)**:`grep "Phase"`——语料写 P1/P2/P3/P4 编号,无 "Phase" 单词 → ③ 0 命中 → ④ 未覆盖 → ⑤ 部分答。**出错:②(词形不匹配)** | "对英文 'Phase' 的检索为 0 命中" |
| **q65** | ②✅(Salesforce 份额) ③**出错(召回)**:dense/lexical 均无 CRM 份额命中(fail6 中 PASS 过,本轮漏召回)→ ④ 未覆盖 → ⑤ 拒答。**出错:③(召回波动)** | "语义检索与关键词检索均未返回...相关文档内容" |
| **q107** | ③**完全失败**:没有任何知识库检索回传 → ④ 无证据 → ⑤ 凭通用知识答"解耦"。**出错:③(检索未执行/失败)** | "当前上下文中没有知识库检索回传" |
| **q141** | ②**出错(检索词)**:`"理论研究"/"现状"/"差距"` 0 命中,语料表述可能不同 → ③ 仅命中原理段 → ④ 拒答。**出错:②(词形/表述不匹配)** | "「理论研究」「现状」等关键词检索均为 0 命中" |

**共同模式**:证据在语料里,但**检索词/召回/提取**某一环断了 → 模型诚实"未覆盖"终答(不是编造,是检索链断裂)。

## 类2:表序/结构化推理错(q86)——出错在 ③(行集不完整)

推理链:① 找"LPDT 在概念阶段的第一个活动" → ② 检索 IPD 表 → ③ **出错**:按"责任人列=LPDT"过滤,但**只看到行 5(LPDT-04)/6(LPDT-08)/7(LPDT-13)**——LPDT-03 行未进回传或未被识别 → ④ 判定"第一个=行 5" → ⑤ 答 LPDT-04。
**出错点**:基于**不完整行集**做"第一个"归纳——模型用"看到的第一个"而非"序号列最小/全部行校验"。正确做法:过滤后应取 `min(行号)` 或确认无遗漏。
**证据**:模型明说"其后的概念阶段 LPDT 活动依次为行号 6、7"——它只看到了 3 行,漏了 LPDT-03。

## 类3:坏运行(q62, q101)——出错在 loop 未收敛(③→⑤ 断裂)

推理链:① 理解问题 → ② 生成检索代码 → ③ 执行并打印 → **出错**:陷入"调试循环"——反复 grep 各种模式、打印命中、调整,没有在证据充分时停止 → ⑤ 答案 = 代码片段,无最终结论。
**出错点**:loop 把"检索调试"当目标,**未在证据足够时收敛到终答**(LLM 采样/预算问题,非 skill 结构)。q62 遍历"supersed/取代/废弃"等模式,q101 同时跑 4 路检索打印——都是调试行为。
**证据**:两题答案以 `<code language="python">` 开头且无 prose 结论。

## 类4:半覆盖即停(q103, q104, q118)——出错在 ④→⑤(覆盖评估后未补检)

以 q103 为例:① 两问(华为 PAC 机制 + 云南白药分级决策) → ② 检索 PAC(大量命中 #4/#13/#15/#17/#18/#19/#2/#16)+ 云南白药分级(#7/#34/#26/#36/#37) → ③ 两路都有实质证据 → ④ **出错**:发现"分级与决策层级对应关系"未覆盖 → **标注未覆盖后直接终答**,没有再补检索(如 grep "S级 决策"/"审批通道") → ⑤ PARTIAL(corr 0.9,faith=1)。
**出错点**:P2 完备性——**半覆盖即停**。注意 q103 圈了 13 个 cite(faith=1),答案是 grounded 的,只是缺失侧未深挖。
**证据**:模型自述"不同级别项目各自对应哪个决策层级...当前回传中未出现明确表述,属于未覆盖部分"后结束。

## 汇总:出错步骤分布

| 类 | 出错步骤 | 题 |

| loop 收敛(⑤) | 调试循环未终止 | q62, q101 |
| 覆盖评估(④→⑤) | 半覆盖未补检即终答 | q103, q104, q118 |
