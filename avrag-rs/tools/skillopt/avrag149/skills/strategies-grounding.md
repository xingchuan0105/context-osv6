# 覆盖边界与跨文档（knowledge-base/strategies-grounding）

按需加载：`{"skill_request": ["knowledge-base/strategies-grounding"]}`。  
多主张清单见 **knowledge-base/strategies**。

## 原则（观察）

- 回传未出现的主张处于 **未知 / 未覆盖**；不等于语料一定没有。
- 邻接数字、编制结构、调研对象**类别**，与「访谈了多少人」「覆盖了几人」等**样本人数**主张不同。
- 跨文档联系需要两侧（或明确声明缺侧）后再写联合句；联合句应能指向回传中的共同抽象或标明概念层推断。
- 文档元数据（doc_profile：类型/体裁/语言）与内容主张是不同层面；画像未记载的字段（如作者、日期）为未知，不按正文推断。
- 回传已有部分命中时，终答侧常见写法是：已覆盖主张分条给出，未覆盖子主张标「当前回传未覆盖」；整题空回/整体拒答在「仍有命中」时与 observation 不一致。仅当检索面完全无命中时，「未覆盖」才覆盖整题，且轨迹里通常能读出检索范围。
- 列举 / 定义 / 「包括哪些」类题：回传覆盖其中任一可核验主张时，即可对覆盖项作答、对未覆盖项标未知；空回不是与「有命中」并存的常态终答形态。
- 题干给出可代入参数并要求计算时，算术结果建立在回传中的参数上；参数槽未覆盖则该结果侧未知。
- 单题多独立子问时，各子问在回传上分别有覆盖/未覆盖状态，终答侧通常分槽交代。

下列 few-shot 使用**与评测语料无关的虚构域**，只说明形态。

## Few-shot

### FS6 — 结构人数 vs 访谈人数

**情境：** 虚构厂区手册问「访谈了多少名现场运维」；回传有「运维编制 6 人」「调研覆盖运维与调度岗」，**无**「访谈了 N 名」字面。

**观察：** 终答对访谈人数写「当前回传未覆盖」；编制与岗位类别可分述，不写成「访谈了 6 人」。

**读出的事实：** 结构人数不能填访谈人数槽。

### FS7 — 跨文档联系

**情境：** 虚构「薪酬手册外部对标」与「设备厂目标市场选择」有何联系。

**观察：** 分别 `dense` 两侧术语；两侧有回传后分源陈述，再写共同抽象（如「与自身条件相称」）；无交叉引用时标明概念层读出。

**读出的事实：** 联系 = 分源覆盖 + 共同抽象有 observation（或明确未覆盖）。

## Gotchas

| 现象 | 回传实际含义 | 常见误读 |
|------|--------------|----------|
| 回传有编制/在编/团队规模，问题问访谈/调研人数 | 结构与样本是不同主张；后者无字面则未覆盖 | 拼接成「访谈了 N 人」 |
| 回传有「覆盖营销人员」无「访谈 N 人」 | 对象类别有 observation；人数未覆盖 | 用编制数或「全部」填人数 |
| 跨文档：两侧均有回传，问「有什么联系」 | 分源；联合结论需共同抽象支撑 | 只分述或编造交叉句 |
| 跨文档仅一侧命中 | 缺侧未覆盖；联系未闭合 | 用已覆盖侧填补缺侧 |
| 知识库+联网，「文章称/文中提到」 | 通常先核文档库 | 只走 web，文档侧前提未覆盖 |
| 多数字题只见一个数 | 其余仍未知 | 只答一半即结束 |
| 问题字面与某段很像 | 相似 ≠ 主张已覆盖 | 跳过精确核对 |
| 谓词类 grep 连续 0 | 谓词可能不逐字出现 | 直接「未覆盖」停搜 |
| dense/lexical 已有目标表述，同词 grep 0 | 覆盖以回传正文为准 | 以 grep 0 否决 chunk |
| 多源数字不一致（同一主张多口径） | 分源分述并标明口径；可给区间/约数式综合 | 只取一个数或拼凑 |
| 问单文档「核心论点/结论」 | 分论点与结论；保留作者自身限定 | 丢掉限定、绝对化 |
| 问文档类型/体裁/语言（doc_profile） | 以画像元数据为准；画像未载字段为未知 | 从正文推断或编造 |
| 回传有部分覆盖，问题列多项要点/措施 | 已覆盖项可答；未覆盖项标未知 | 因部分缺失整体空回，或只答一项即止 |
| 列举/定义题字面未逐字命中 | 覆盖以回传主张为准 | 空回或整体拒绝 |
| 题干给参数要求计算 | 用回传参数做算术；缺参则未知 | 只搜现成总数或编造参数 |
| 单题多独立子问 | 各子问分别覆盖/未覆盖 | 只答其中一个子问即止 |
