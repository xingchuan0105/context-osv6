## 图扩邻种子策略

`client.dense(query)` 的 `query` **同时**驱动向量召回，并作为宿主关系扩邻（VGRAG）的种子文本来源：宿主从 query 与 top dense 命中里切出短词/CJK 片段作为种子，再 hop 扩邻、融回同一 chunk 列表。沙箱侧**没有**独立的 `client.graph`；LLM 侧可控制的主要是 **query 粒度与并行次数**。

**种子粒度与扩邻方向**

- 单次 `dense` 的 query 越贴近**可独立核验的实体/专名短语**（可选附最短属性槽），切出的种子越集中，扩邻方向通常越稳。
- 含多实体、多主张的**整句疑问**作为唯一种子时，宿主会从长句里切出多个方向的词片段；扩邻向多端漫散，回传常主题相关但主张不全。
- 种子文本与语料/节点 label 的**原始术语**对齐时，向量与图匹配更稳；同义改写、概念化长句会偏移到错误邻居。
- 属性槽取最短、有区分度的词（如 `索书号`）比描述性短语（如「书目里面的号码」）更利于种子对齐。

**问题形态 → 常见 dense 扇出**

| 问题形态 | 常见 dense 形态 | 读出的机制 |
|----------|-----------------|------------|
| 单主张、单实体 | 一次 `dense("实体名")` 或 `dense("实体名 属性槽")` | 一种子方向 |
| 单实体、数值/量化（台数/金额/占比/直径/票房/人数/规模） | `dense("实体 最短指标词")` **并行** `lexical`/`grep` 锚定精确数值 | 数值在正文/表格，词面锚定更稳 |
| 单主张、关系型（A 与 B） | 同块两次独立 `dense`，种子分别为 A、B | 两端邻域有机会汇合 |
| 多主张 | 每主张/实体一次 `dense`，同块并行 | 清单可分项打勾 |
| 跨文档对照 | 每侧实体各一次 + 可选 `doc_ids` | 避免一侧淹没另一侧 |

**饱和后的下一步（图向）**

- 连续多轮仅对**同一实体**做整句同义改写、新 alias≈0：该种子面已饱和。
- 关系型或双端题上，A 侧饱和时，轨迹里更有效的一步是**换实体角度**（以 B、或回传中出现的中间专名为种子），而不是继续改写 A 的问法。
- 表内计数/字面转向 struct/grep（见 **strategies-tables**），不依赖「再改写 dense 就会出关系链」。
- 单实体数值/量化题（直径、票房、访谈人数、市场规模、占比）的答案是**精确数字或具体段落**：用「实体 + 最短指标词」dense 并**并行 lexical/grep 锚定**该数值；图扩邻在此类题上只是辅助，不指望 hop 出精确数字。

下列 few-shot 使用**与评测语料无关的虚构域**，只说明形态。

## Few-shot

### FS1 — 单实体属性字段

**情境：** 用户问虚构「北岭市立图书馆」书目索书号/馆藏楼层。

**观察：** `dense("北岭市立图书馆 索书号")` 或 `dense("书目 馆藏楼层")`，并与 `lexical` / `grep` 字段探测并行。

**读出的事实：** 检索词偏 **专名 + 属性槽**；该短串同时是扩邻种子。

### FS2 — 两主张 / 跨材料

**情境：** 说明书 A 的「FluxPipe」与手册 B 的「AL-9」如何衔接。

**观察：** 同块 `dense("FluxPipe")` 与 `dense("AL-9 告警")`，而非仅一次整段原句 dense。

**读出的事实：** 多主张按实体拆 dense；两端独立种子后再读衔接。

### FS4 — 列表枚举（非计数）

**情境：** 课表模块「选课限制」列了哪几类。

**观察：** `dense("选课限制 类型")` 与 `lexical("限制")` 并行；枚举出现在回传正文后再 SELECTED。

**读出的事实：** 列表题 dense 偏主题+分类线索，依赖回传枚举句。

### FS5 — 关系型双端种子

**情境：** 「HelixGate」与「ST-17」有何依赖或布置关系。

**观察：** 同块 `dense("HelixGate")` 与 `dense("ST-17")`，而非 `dense("HelixGate 和 ST-17 有什么关系")`。

**读出的事实：** 关系型入口是两端各一种子；A 侧饱和时补 B 侧。

## Gotchas（图 / dense 词面）

| 现象 | 回传实际含义 | 常见误读 |
|------|--------------|----------|
| 整句多实体作唯一 `dense` | 扩邻种子散；主张可能不全 | 未按实体拆、未补缺侧 |
| 一次 `dense("A 和 B 的关联")` | 单种子方向不定 | 以为「关系」二字会出路径 |
| 连续多轮仅同义改写同一实体 | 该种子面饱和 | 以为再改写会出关系链 |
| 纯金额/台数/占比/ADR 代号作 dense 唯一种子 | 图侧常 `graph_n=0`；词面更贴 | 空转 dense 未并行 lexical/grep |
| 单实体数值/量化题（直径/票房/人数/规模）作唯一种子 | 答案在具体段落/精确数字，词面锚定更稳 | 只做 dense 空转、未并行 lexical/grep |
| `dense` 走 vgrag 但图证据未进列表 | 语义池仍可能有正文 | 把「无图」读成「无答案」 |
| `client.dense` 回传非空 | 列表内可能已含扩邻正文 | SELECTED 漏圈本列表 alias |
