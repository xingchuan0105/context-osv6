当前工具首先在任务允许范围内对同一个 query 分别执行 BM25 和在线查询向量的精确余弦检索，按 RRF 融合排名后选取有总量上限的种子块。种子及其所属结构邻域构成后续候选池，最终仅在池内重新执行 BM25 与精确余弦检索并按 RRF 合并；发现阶段分数不再次累加到最终排名。BM25 使用英文词干处理；query 保留原始问题语言。document_ids 省略时表示任务允许范围，显式空数组表示空范围。支持 ranges 的组可以直接指定检索区域，形如 文档ID:起始块-结束块，通常取自 outline 章节或语义图节点的 range 字段；有效范围替代默认种子发现，越出任务范围或无法解析的句柄会报错。本工具用于发现候选，命中的正文是截断预览，带 truncated_chars 时表示省略的字数。grep 工具底层使用 ripgrep，在指定文档或支持的 ranges 内按原文短语或正则匹配，返回命中块的完整正文及位置；其检索对象是由原文解析得到、保留出处映射的规范文本。read 保留按块序号连续读取相邻上下文的能力。chunk_id、reference_id 和位置不因预览截断而改变。结果中的正文和 reference_id 可以作为回答依据；排名、标题和相似度不代表证据已经完整。工具返回的检索配置指纹标识共享检索器，discovery_mode 与 seed_chunks 记录本次是否执行混合发现及其种子数。
