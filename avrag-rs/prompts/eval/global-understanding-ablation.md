# 文档理解消融评测

本评测的输入包括问题、参考答案、模型回答以及从冻结正文中核对过的证据片段。参考答案是事实与覆盖范围的参考，不是逐字匹配模板。证据中作者的观点属于文档所表达的观点，不代表已经核实的外部世界事实。

评分的三个维度彼此独立：

- correctness：回答的事实、关系及限定条件与参考答案和正文的一致程度。合理同义表达等价；数量、主体、日期错误影响此维度。参考答案与正文冲突时，冲突记入 issues，评分不伪装成确定结论。
- completeness：问题中各个请求点得到回答的比例。正文实际包含答案时，承认未找到体现诚实，但对应请求点仍未覆盖。仅回答背景信息也不构成该请求点的覆盖。
- grounding：回答的实质性主张在所给正文证据中的支持程度。明确标为推断且有正文依据的类型、体裁判断，与声称画像中存在该字段是两种不同主张。没有证据的具体数字、实体和关系记录为 unsupported_claims。

generated_archive 是额外的接触记录，仅说明模型获得过哪些预生成材料；它不充当正文事实的依据。工具调用次数也不充当答案正确性的依据。题面没有对话历史时，没有记忆题免评或占位满分。

输入中的 required_points 若存在，就是预先冻结的请求点清单；完整性分数等于已覆盖点数除以总点数。遗漏某个点影响完整性，不会使已经给出的正确事实自动变成错误事实。

正文语言本身可以支持语言判断；可观察的论点与论证结构可以支持标明为推断的体裁分类。没有显式元数据标签不等于缺少这些推断的依据。unsupported_claims 只包含实际无支持或与证据矛盾的主张，不包含已经确认“内容支持”或“有据合理推断”的主张。

证据可能无法充分验证某个主张。该情形记录为 grounding.score=null、grounding.status="insufficient_evidence"，并列出待核对主张；证据不足不是已经证实主张错误。明显不受已给证据支持的扩写记录为 unsupported_claims。事实正确性和完整性仍按可判断部分评分，不确定部分记录在 issues。

输出是单个 JSON 对象，结构如下。各 score 为 0 到 1 的数值，grounding.score 也可为 null；列表为空时为 []。

{"correctness":{"score":1.0,"rationale":""},"completeness":{"score":1.0,"covered":[],"missing":[]},"grounding":{"score":1.0,"status":"supported","unsupported_claims":[],"unverified_claims":[]},"issues":[]}
