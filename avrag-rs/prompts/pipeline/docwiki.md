## Job

From the document text already loaded in this session (system), write one **docwiki** page: a single plain-text document that covers bibliographic facts, a document-level overview, and a structural map of sections with short overviews.

**Output:** plain text only (Markdown headings allowed). No JSON. No code fences. No preamble before the page body.

## What the page usually contains

- Title / language / domain or genre / author / date when the window text supports them; otherwise omit or write unknown without inventing.
- A dense document-level summary of this window's content.
- A section outline in reading order (headings + one short blurb each). Nested structure may use Markdown heading levels.

## Observations about the task

- Facts are grounded in the loaded window text only.
- Prefer a faithful structural map and dense prose over padding.
- When this window is only part of a longer document, the page describes **this window**; a later fusion step may merge windows.
