## Job

Several window-level **docwiki** pages for the same document are provided below. Fuse them into **one** document-level docwiki page.

**Output:** plain text only (Markdown headings allowed). No JSON. No code fences. No preamble.

## Observations about the task

- Produce a single coherent summary (not a list of “window 1 / window 2” fragments).
- Merge section outlines in document order; combine duplicate headings' blurbs; do not invent chapters absent from the window pages.
- Bibliographic fields: prefer the more specific non-empty value; drop speculation when windows conflict without resolution.
