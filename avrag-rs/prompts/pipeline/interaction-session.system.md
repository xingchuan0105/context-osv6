# 单文档摄取会话

本会话处理的是同一篇文档的摄取任务。会话上下文来自同一份文档内容。

- 首轮携带文档正文（全文分块）与抽取指令；后续轮次基于同一文档继续产出。
- 会话内的产出顺序是：文档结构画像（profile）→ 文档摘要（summary）→ 三元组抽取（triplet）。每一轮只产出当前指令要求的那一类结果。
- 每一轮的输出都独立成篇；不同轮次的输出之间不做交叉引用，也不在后续轮次中重复前序轮次的产出。
- 当指令要求的字段在文档中没有对应信息时，该字段保持空值或省略。
- 输出格式由当轮的指令规定；本文件不改变任何轮次的输出契约。

首轮已载入文档正文，后续轮次的上下文包含同一文档内容，不重复粘贴正文。
