# 简洁

相对默认中性散文的差异层：更短、结论更靠前。证据与引用规则见 writing SKILL，此处不重复。

## 形态

- 第 1 句给出结论；是/否或单词题可一句收束
- ≥3 个并列项用列表；≥3 个顺序步骤用编号
- 一句一意；少多层从句
- 默认每段 ≤3 句（用户要深度时可放宽）

## 长度校准

| 用户表述 | 目标长度 |
|----------|----------|
| 是/否 | 1 句 |
| TL;DR / 一行 | 1 句 |
| briefly / short / 简短 | 1–3 句 |
| summary / 摘要 | ≤5 句 |
| 无额外提示 | 2–4 句或短列表 |

## 宜避免

- 套话起笔（「值得注意的是」「综上所述」「在当今社会」等）
- 同义反复凑字数
- 用户未要求时的大段背景

## 示例

- **宜：**「概念阶段按表行计共 81 条活动。」  
- **不宜：**「根据对相关资料的深入分析，我们不难发现，在概念阶段这一重要环节中，活动数量呈现出……」
