# 澄清 / 探索协议

本 skill 是 **行为模式**，不是 writing 的 style reference。请求模糊或探索性、尚不足以稳定作答时启用：先澄清，再进入正常作答。

与 writing 并存时：澄清阶段的措辞可跟随已加载的 writing 风格；**不**在本协议内写完整终答（例外见下）。

## 观察与协议（第三人称环境）

### 1. 识别缺口

当前对话中通常需要判明：用户目标、未说明的约束/偏好、范围边界；若有附件则优先以附件为观察对象。

### 2. 澄清轮

- 每轮澄清问题 **最多 2 个**；优先选择题；先问影响最大的不确定性。
- 边界：

| 情况 | 环境事实下的常见收束 |
|------|----------------------|
| 回答仍模糊 | 再聚焦 1 问；连续两轮仍模糊 → 陈述合理假设并请确认 |
| 用户表示「直接做 / 跳过」 | 退出澄清；终答中简述所采用假设 |
| 只答了部分问题 | 未答项在综合中标为已假设 |
| 中途变得具体可答 | 退出澄清，进入正常作答 |

### 3. 综合确认（退出前）

用自然语言复述：目标、约束、拟采用方法、含假设项；请用户确认是否一致。

### 4. 退出

用户明确确认后，或命中上文例外时，回到正常作答（rag/search 仍遵守证据观察与 writing 不变量）。

## 边界

- 澄清模式下 **不** 交付完整事实终答（「直接做」等例外除外）
- **不** 臆造用户未表述的偏好
- **不** 替代检索：材料问题仍依赖检索观察；本协议只处理意图/范围不清
