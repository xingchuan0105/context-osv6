# Context-OS 帮助文档内容（V1）

更新时间：2026-04-13  
用途：用于前端帮助中心 Wiki 页面渲染与后续 CMS 化。

## 中文版

1. 账户与认证：支持注册、登录、登出、改密、邮件验证码重置密码。  
2. Workspace 管理：支持创建/编辑/删除 notebook，上传文档与 URL 资料源。  
3. 会话能力：支持会话创建、重命名、删除，消息列表与引用内容查看。  
4. 历史检索：在 Workspace 通过“历史”按钮按关键词检索线程并跳转。  
5. 分享能力：可生成分享链接、配置分享策略、查看分享访问分析与日志。  
6. 协作邀请：支持成员邀请、接受/拒绝邀请、成员移除。  
7. API 访问：支持 Workspace 级 API Key 创建、列表查询与吊销。  
8. 通知与偏好：支持通知读取与偏好保存（dashboard 草稿等）。  
9. 额度信息：支持查询 usage-limit，用于展示本月额度与剩余可用量。  
10. 运行状态：提供 health/ready/metrics/openapi/docs 等基础运维入口。  

## English

1. Account & Auth: register, login, logout, password change, and email code reset.  
2. Workspace Management: create/update/delete notebooks, upload files, and add URL sources.  
3. Sessions & Messages: create, rename, delete sessions, and browse message history.  
4. History Search: use the History button in workspace to find threads by keyword.  
5. Sharing: generate share tokens, manage share settings, and inspect access analytics/logs.  
6. Collaboration: invite members and accept/decline/remove membership requests.  
7. API Access: create/list/revoke notebook-scoped API keys.  
8. Notifications & Preferences: read notifications and persist user preferences/drafts.  
9. Quota & Limits: query usage-limit to show monthly limit, used amount, and remaining quota.  
10. Ops Endpoints: health/ready/metrics/openapi/docs for runtime observability.
