# Issue Tracker: Local Markdown

Issues for this repository are tracked as markdown files in the `.scratch/` directory.

## Workflow

1. **Create an issue**: Create a new `.md` file under `.scratch/<feature-name>/`.
2. **Naming**: Use descriptive filenames, e.g., `123-fix-sse-leak.md`.
3. **Format**: Use a consistent header (Title, Status, Labels, Description).
4. **Skills**:
   - `to-issues`: Will write new files to this folder.
   - `triage`: Will read and update status/labels in these files.
